**Key Technical Concepts**
- **Staging & Approval Workflow:** A two-step data ingestion process where crawled data is held in a temporary staging area for manual review before being promoted to the live production database.
- **Data Normalization:** Standardizing data for reliable matching, such as converting Street and St. to a consistent format and cleaning unit numbers.
- **Deduplication Strategy:** Using normalized data to identify potential duplicates, assigning a score, and flagging them for review rather than blocking them outright.
- **Database Seeding:** A pattern for populating a database using a script that reads from static data files (e.g., JSON), ensuring a consistent starting state.
- **Role-Based Database Access:** Creating a dedicated software layer to act as a gatekeeper, ensuring that only specific, authorized parts of the application can write to critical database collections.
