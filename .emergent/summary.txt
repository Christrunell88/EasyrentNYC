The user wants to build a web application called NoFeesApts.com that functions similarly to nofeeplaces.com. The primary feature is to crawl publicly available real estate websites for no-fee apartment listings in NYC, Northern New Jersey, and PA, and display them.

**PRODUCT REQUIREMENTS:**
- **Core Functionality:** Crawl websites to gather apartment data (Address, unit number, rent, bedrooms, baths, images, amenities).
- **Database:** Use MongoDB to store all crawled data.
- **Authentication:** Support JWT-based custom sign-up/login and Google social login.
- **Web Crawler:** Should run automatically every 48 hours, with a manual trigger button in an admin panel.
- **Frontend:**
    - Display apartment listings with search, filters, and an interactive map view.
    - Favorites feature for logged-in users.
    - A smart, intuitive, sexy, sleek, and modern design, currently a Luxury Dark Theme.
    - Sign up for full details feature with blurred addresses on the landing page.
- **AI Search Agent:** A clever, creative AI search agent (Ask Chris) for users to find units on and off the site. The agent should be powered by Gemini, save searches for admin review, and be available only to logged-in users.
- **SEO:** The site should be optimized for search engines, including a dynamic sitemap, descriptive alt text, and structured data (Schema.org).
- **Admin Panel:** An admin-only section to view listings, analytics, and trigger crawls.
- **Notifications:** Send email notifications for contact form submissions and a welcome email for new user sign-ups.
- **Appointment Scheduling:** Allow users to request a tour date/time, and integrate with Google Calendar.
