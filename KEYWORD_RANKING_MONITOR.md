## Free Monitoring Tools

### 1. Google Search Console
**Setup:**
- Already configured in your account
- Check "Performance" tab weekly
- Monitor: Clicks, Impressions, CTR, Position

**What to Track:**
- Total impressions for each keyword
- Click-through rate (target: >3%)
- Average position (goal: page 1 = positions 1-10)

### 2. Bing Webmaster Tools
- Similar to Google Search Console
- Often shows rankings faster
- Good for Bing/Yahoo traffic

### 3. Manual Ranking Checks
**Weekly Checklist:**
1. Open incognito browser
2. Search each primary keyword
3. Record position (or "not in top 50")
4. Track in spreadsheet
