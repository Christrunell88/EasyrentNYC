## 📊 SETUP INSTRUCTIONS

### Google Ads Steps:
1. Go to **Tools & Settings** → **Shared Library** → **Negative Keyword Lists**
2. Click **+ (plus icon)** to create new list
3. Name it: "NoFeesApts - Master Negative Keywords"
4. Paste keywords from above sections
5. Save list
6. Apply to all relevant campaigns

### Match Types:
- Use **broad match** (default) for most negative keywords
- Use **exact match** [keyword] for specific terms you want to block precisely
- Use **phrase match** "keyword" for multi-word negative keywords

### Example Match Types:
```
section 8           (broad - blocks any search containing these words)
[section 8 housing] (exact - only blocks this exact search)
"apartments for sale" (phrase - blocks searches containing this phrase)
```
